# منشئ الاختبارات للمعلمين — PWA

تطبيق جاهز للبناء والنشر على GitHub Pages.

## المزايا

- React + TypeScript + Vite.
- PWA قابل للتثبيت ويعمل بعد تحميله دون اتصال.
- حفظ المسودات في IndexedDB.
- RTL عربي.
- بناء أسئلة: نصي، اختيار متعدد، ربط، وضعية إدماجية.
- حساب مجموع النقاط تلقائيًا.
- كتلة خاصة للآيات مع فصل الخط القرآني عن النص العادي.
- طباعة A4 عبر محرك الطباعة في المتصفح، وهي المسار الأكثر ثباتًا للنص العربي مقارنة بإعادة تشكيله داخل مكتبة PDF.
- دعم حفص وورش على مستوى بنية التطبيق.
- GitHub Pages عبر GitHub Actions.

## مهم جدًا قبل الاستخدام الفعلي للقرآن

المشروع يتعمد عدم تضمين خطوط KFGQPC أو قاعدة القرآن الكاملة من مصدر غير رسمي.
يجب تنزيل ملفات الخط والبيانات من منصة مطوري مجمع الملك فهد ثم وضعها في:

public/fonts/kfgqpc-hafs.ttf
public/fonts/kfgqpc-warsh.ttf
public/quran/hafs.json
public/quran/warsh.json

صفحة المطورين الرسمية:
https://qurancomplex.gov.sa/en/techquran/dev/

لا تستخدم النصوص التجريبية أو مصادر مجهولة عند إعداد امتحان فعلي.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع كامل المشروع.
3. اذهب إلى Settings > Pages.
4. اختر Source = GitHub Actions.
5. ارفع/اترك ملف `.github/workflows/deploy.yml`.
6. ادفع التغييرات إلى main.

سيقوم GitHub ببناء التطبيق ونشر مجلد dist تلقائيًا.

## الطباعة

من التطبيق اضغط:
طباعة / PDF

ثم اختر الطابعة:
Save as PDF

واجعل:
- Paper: A4
- Scale: 100%
- Margins: None أو حسب إعداد الصفحة
- Headers and footers: Off

## ملاحظة تقنية

لا تعتمد على 300DPI للنصوص. النص المتجهي يعتمد على الخط وتشكيل OpenType.
لذلك تم فصل كتلة القرآن عن النص العادي واستخدام الخط القرآني فقط داخلها.

## التحقق

قبل نشر النسخة الرسمية، اختبر مجموعة من الآيات التي تحتوي على علامات ضبط معقدة،
وخصوصًا من الرواية التي ستستخدمها المدرسة.
