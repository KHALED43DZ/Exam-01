# الخطوط القرآنية

لضمان سلامة عرض الآيات، ضع هنا ملفات الخط الرسمية التي تحصل عليها من منصة مطوري
مجمع الملك فهد لطباعة المصحف الشريف.

الأسماء التي يتوقعها التطبيق:
- `kfgqpc-hafs.ttf`
- `kfgqpc-warsh.ttf`

لا تضع خطًا من مصدر مجهول. التطبيق يستخدم الخط القرآني فقط داخل كتل الآيات، بينما
النص الإداري والأسئلة يستخدمان خط النظام/الخط العربي العادي.

المصدر الرسمي:
https://qurancomplex.gov.sa/en/techquran/dev/

بعد إضافة الخطوط، أعد `npm run build`.
