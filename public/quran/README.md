# بيانات القرآن

ضع بيانات القرآن الرسمية هنا بعد تنزيلها من منصة مطوري مجمع الملك فهد.

الملفات المتوقعة:
- `hafs.json`
- `warsh.json`

كل عنصر JSON يجب أن يكون بالشكل:

{
  "id": "2:153",
  "surahNumber": 2,
  "surahName": "البقرة",
  "ayahNumber": 153,
  "uthmani": "...النص العثماني المعتمد...",
  "searchText": "...نص البحث..."
}

يمكن أيضًا وضع مصفوفة مباشرة:
[
  { "...": "..." }
]

التطبيق لن يعتبر النص الملصق قرآنًا موثقًا إلا إذا وجده في قاعدة البيانات المحلية.
